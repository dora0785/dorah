# Nalwanyiri Dorah Portfolio

A responsive personal portfolio website for Nalwanyiri Dorah, a technical support engineer. The site presents her professional profile, experience supporting cloud and on-premises environments, selected projects, technical certificates, and contact information.

## Features

- **About section:** Introduces Dorah and her technical support focus.
- **Selected work:** Highlights tenant migration and cloud/on-premises troubleshooting experience.
- **Certificates:** Presents NDG Linux Unhatched and Networking Devices and Initial Configuration certificates.
- **Contact links:** Provides direct phone and email access.
- **Responsive design:** Adapts the layout for desktop and mobile screens.
- **Accessible navigation:** Uses semantic sections, descriptive image text, and clear internal links.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 4.4.1 base styles
- Google Fonts (DM Sans and Playfair Display)
- Inline SVG icons

## How to Run This Project

This is a static website, so it does not require a build process or package installation. It can be opened directly in a modern browser or served with a local development server.

### Prerequisites

- A modern web browser such as Chrome, Firefox, Edge, or Safari
- Git, if cloning the repository
- Optional: the VS Code Live Server extension

### Installation

1. Clone the repository:

	```bash
	git clone https://github.com/dora0785/dorah.git
	```

2. Move into the project directory:

	```bash
	cd dorah
	```

3. Open the project in VS Code:

	```bash
	code .
	```

4. Open `index.html` in a browser, or right-click it in VS Code and select **Open with Live Server**.
